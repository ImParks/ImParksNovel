# HR 제안서: hr-manager 스킬 할당 업데이트 + CLAUDE.md 생성

- **제안자**: hr-manager
- **유형**: 업데이트 (스킬 할당) + 신규 파일 생성 (CLAUDE.md)
- **날짜**: 2026-03-27

---

## 변경 1: claude-md-manager 스킬을 hr-manager에 할당

### 변경 사유

`claude-md-manager` 스킬이 roster.json에 등록되어 있으나 어떤 에이전트에도 할당되지 않은 상태였다.
CLAUDE.md는 HR Manager가 조직 초기 세팅 및 관리 시 생성/수정해야 하는 파일이므로, HR Manager에게 이 스킬을 할당하는 것이 적합하다.

### 변경 내용

#### 변경 전
```yaml
skills:
  - agent-manual
  - agent-creator
```

#### 변경 후
```yaml
skills:
  - agent-manual
  - agent-creator
  - claude-md-manager
```

### 영향 파일
- `.claude/agents/hr-manager/AGENT.md` — skills frontmatter 업데이트
- `logs/hr/roster.json` — claude-md-manager의 assigned_to에 hr-manager 추가
- `logs/hr/skill-assignments.json` — hr-manager 스킬 목록에 claude-md-manager 추가

### 영향 분석
다른 에이전트에는 영향 없음. HR Manager의 컨텍스트 비용이 소폭 증가하나, CLAUDE.md 관리 책임을 명확히 하는 데 필요한 비용이다.

---

## 변경 2: 프로젝트 루트 CLAUDE.md 생성

### 변경 사유

프로젝트 루트에 CLAUDE.md가 없어 Claude Code가 프로젝트 컨텍스트를 자동으로 파악할 수 없는 상태였다.
CLAUDE.md를 생성하여 모든 에이전트와 Claude 인스턴스가 프로젝트 구조, 기술 스택, 에이전트 시스템, Git 워크플로우를 즉시 파악할 수 있도록 한다.

### 생성 파일
- **경로**: `CLAUDE.md` (프로젝트 루트)
- **분량**: 200줄 이내

### 포함 내용
1. 프로젝트 개요 및 기술 스택
2. 디렉토리 구조 요약
3. 메인 Claude의 Director 역할 정의 및 파이프라인 위임 구조
4. 에이전트 시스템 참조 경로
5. Git 워크플로우 참조
6. 개발 명령어
7. 코딩 규칙 요약

### 관리 원칙 준수
- 에이전트 매뉴얼과 중복 없음 (참조만)
- 에이전트별 규칙은 AGENT.md에, 스킬별 규칙은 SKILL.md에 위임
- claude-md-manager 스킬의 관리 원칙 준수 (간결, 중복 배제, 정확한 정보)

### 영향 분석
모든 Claude 인스턴스가 대화 시작 시 프로젝트 컨텍스트를 자동으로 로드하게 된다. 에이전트들의 초기 컨텍스트 파악 시간이 단축되고, 방향성 오류가 감소할 것으로 기대된다.
