| 항목 | 내용 |
|------|------|
| **유저 스토리** | 사용자로서, 이메일/소셜 계정으로 회원가입하여 플랫폼을 이용할 수 있다 |
| **Phase** | MVP |
| **MoSCoW** | Must |

**수용 조건**:
- AC1: Given 비회원 사용자가 회원가입 페이지에 접근했을 때, When 이메일/비밀번호/닉네임을 입력하고 가입 버튼을 클릭하면, Then 계정이 생성되고 이메일 인증 메일이 발송된다
- AC2: Given 비회원 사용자가 회원가입 페이지에 접근했을 때, When 소셜 로그인(Google/Kakao/Naver) 버튼을 클릭하면, Then 소셜 계정 연동 후 계정이 생성된다
- AC3: Given 이미 가입된 이메일로 회원가입을 시도할 때, When 가입 버튼을 클릭하면, Then "이미 가입된 이메일입니다" 오류 메시지가 표시된다

- AC2: Given 소설 생성 시, When 필수 항목(제목, 장르, 시놉시스)이 누락되면, Then 해당 항목에 대한 입력 오류가 표시된다

|------|------|

| **Phase** | MVP |
| **MoSCoW** | Must |

- AC2: Given 연재 중인 소설의 장르를 변경할 때, When 기존 독자에게 영향을 줄 수 있으므로, Then 장르 변경 확인 모달이 표시된다

### FEAT-NOVEL-003: 소설 연재 상태 관리
| 항목 | 내용 |
|------|------|
| **유저 스토리** | 작가로서, 소설의 연재 상태(연재중/휴재/완결)를 변경할 수 있다 |
| **Phase** | MVP |
| **MoSCoW** | Must |

**수용 조건**:
- AC1: Given 연재 중인 소설이 있을 때, When 작가가 연재 상태를 "완결"로 변경하면, Then 소설이 완결 상태로 전환되고 독자에게 완결 알림이 발송된다
- AC2: Given 휴재 상태의 소설이 있을 때, When 작가가 새 회차를 발행하면, Then 자동으로 "연재중" 상태로 전환된다
- AC3: Given 연재중인 소설에서, When 설정된 연재 주기 대비 일정 기간(예: 2주) 이상 새 회차가 없으면, Then "연재지연" 마크가 자동으로 부여된다
- AC4: Given 연재지연 마크가 부여된 후, When 추가로 일정 기간(예: 1개월) 이상 새 회차가 없으면, Then "연재중단" 마크로 전환된다
- AC5: Given 연재지연/연재중단 마크가 부여된 후, When 작가가 새 회차를 발행해도, Then 일정 기간(예: 2주간 2회 이상 연속 연재) 꾸준히 연재해야 마크가 해제된다
- AC6: Given 연재지연/연재중단 마크는, When 소설 상세 페이지와 검색 결과에서 독자에게 표시되어, Then 연재 상태를 투명하게 확인할 수 있다
